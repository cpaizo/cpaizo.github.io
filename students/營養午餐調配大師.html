🎯 第一章：專案主題與核心規則說明

本專案要求學生設計一款具備「雙向數值限制」的條件配對模擬遊戲。以「營養午餐」為例，學生必須遵守以下規格：

  • 4 大分類與選項：畫面必須劃分 全榖雜糧類、豆魚蛋肉類、蔬菜類、水果/乳品類，每類至少 5 個選項。
  • 雙向熱量區間管制：
    • 上限管制：總熱量不可超過校長規定的最高極限（避免熱量爆表）。
    • 下限管制：總熱量不可低於最低門檻（避免吃不飽或營養不良）。
  • 互動與通關機制：不使用傳統干擾的 `alert()`，改用畫面即時提示訊息框；完成 5 道隨機題目並計算總花費時間。

🧠 第二章：核心知識點（健康教育與數學邏輯）

  • 六大類食物均衡概念：落實日常飲食指南，理解不同食物對身體的營養價值。
  • 熱量預算控制（數值區間）：培養動態加減運算能力，在限制條件內做出最佳決策。
  • 演算法與條件判斷 (`if/else`)：學會撰寫同時檢查「大於等於下限」且「小於等於上限」的程式防呆邏輯。

💻 第三章：網頁程式開發核心技巧解析

本遊戲採用單檔案架構，核心程式碼運用了以下關鍵技術：

1. CSS Grid 排版與動態進度條：使用格狀系統讓 5 個圖標按鈕完美對齊，並透過 CSS `transition` 讓健康進度條平滑推進。

/* 網格按鈕排版 */
.btn-grid {
    display: grid;
    grid-template-columns: repeat(5, 1fr);
    gap: 6px;
}
/* 進度條動畫 */
.progress-bar-fill {
    width: 0%;
    transition: width 0.4s ease;
}

2. 即時動態總量計算與區間驗證 (JavaScript)：

// 點擊按鈕時即時累加總熱量並變色提示
function selectOption(category, value, calories, cardElement) {
    playerChoice[category + 'Cal'] = calories;
    let sum = playerChoice.grainCal + playerChoice.proteinCal + ...;
    
    if (sum < targetMinCal) {
        calSpan.style.color = 'orange'; // 太低
    } else if (sum > targetMaxCal) {
        calSpan.style.color = 'red';    // 爆表
    } else {
        calSpan.style.color = 'green';  // 完美達標
    }
}

✅ 第四章：學生期末專案驗收規格表 (Checklist)

請各組同學在繳交專案前，逐項勾選確認是否達成目標：

自訂創意主題（如：魔法藥水、宇宙補給站、健康便當）。
建立 4 大分類，每類包含 5 個帶有圖標與數值標籤的圖片按鈕。
實作「雙向上下限管制」，點擊時能即時計算數值並給予回饋。
拿掉 alert 彈跳視窗，改用畫面即時提示與健康進度條。
具備 5 道題目的隨機出題與總花費時間計時器。
