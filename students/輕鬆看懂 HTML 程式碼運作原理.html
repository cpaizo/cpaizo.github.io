🔍 HTML 程式碼解密手冊

給學生的網頁前端小學堂：帶你拆解「營養午餐遊戲」的祕密！

🧱 技巧一：HTML 就像蓋房子（結構標籤）

網頁是由一層一層的「標籤 (Tags)」包起來的。就像洋蔥一樣，有開頭就有結尾（例如 <div> 跟 </div>）。

<!-- 遊戲的最外層大卡片盒子 -->
<div class="game-card">
    <h1>🥗 營養午餐調配大師 </h1>
    
    <!-- 顯示訂單與提示的區域 -->
    <div id="orderText">準備開始...</div>
</div>

🎨 技巧二：用 CSS Grid 讓按鈕排排站

我們希望畫面上有 5 個選項平均排列。不要傻傻自己算位置，只要用 CSS 的格狀排版（Grid），電腦就會自動幫你排得整整齊齊！

/* CSS 樣式設定 */
.btn-grid {
    display: grid;                             /* 宣告使用網格排版 */
    grid-template-columns: repeat(5, 1fr);     /* 自動分成 5 等份欄位 */
    gap: 6px;                                    /* 按鈕跟按鈕之間的間距 */
}

🖼️ 技巧三：做出會發光、有圖標的互動按鈕

我們用一個小格子盒子（<div>）包住圖片與文字，當滑鼠點下去時，透過 JavaScript 觸發 onclick 動作！

<!-- 一個食物選項按鈕：包含圖片、名稱與卡路里標籤 -->
<div class="img-btn" onclick="selectOption('grain', '糙米飯', 150, this)">
    <img src="https://cdn-icons-png.flaticon.com/512/3174/3174834.png">
    <span>糙米飯</span>
    <span class="cal-tag">150大卡</span>
</div>

⚡ 技巧四：用 JavaScript 幫你算熱量與防呆

JavaScript 是網頁的大腦。當玩家點擊按鈕時，大腦會立刻把熱量加起來，並檢查有沒有符合校長規定的「上下限區間」：

// 檢查總熱量是否在安全區間內
if (playerChoice.totalCal >= targetMinCal && playerChoice.totalCal <= targetMaxCal) {
    alert("🎉 完美達標！進入下一題！");
} else {
    alert("💥 熱量超出範圍！請重新調整！");
}
💡 老師的小叮嚀：同學們在寫自己的專案時，可以把這幾個核心程式碼區塊（HTML 結構、CSS 網格、JS 點擊函數）當作模板，修改裡面的文字和數字，就能輕鬆做出你的專案囉！🚀
