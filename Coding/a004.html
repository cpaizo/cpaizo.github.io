第 4 單元教案｜資料視覺化 × 分類統計 × 單檔 HTML 互動網頁

讓數據自己說話：用提示詞打造《班級投票》與《閱讀／生活習慣統計》互動頁

本單元帶老師與學生把零散的調查、投票或日常紀錄，轉化成能即時計算、切換視覺呈現與分類統計的單檔 HTML 網頁。 手冊同時提供情境 A（班級即時投票與長條圖）與情境 B（每週閱讀與生活習慣分類統計），讓老師依課堂目標彈性選擇。

適用年級 國小中～高年級
建議節數 2 節課（共 80 分鐘）
雙情境範例 情境 A 投票長條圖 / 情境 B 習慣統計
技術特色 純單檔 HTML、免外部圖表套件

一、 教學目標與核心知識點

📊 資料統計與視覺化知識點
  • 總數、比例與平均：學會從原始紀錄看出「總共幾筆／幾票」、「占百分之多少」以及「平均每天／每週是多少」。
  • 分類與門檻判讀：依據設定的標準（例如每週閱讀達標門檻或生活習慣等級）進行分類，一眼看出狀態。
  • 視覺化幫助比較：用長條比例或清楚卡片呈現，比單看一長串數字更容易發現「最多／最少」與「差異」。
🤖 統計類網頁的提示詞重點
  • 清楚定義「輸入」與「計算規則」：告訴 AI 按下按鈕或輸入數字時，總數、百分比或分類等級要怎麼算。
  • 指定「零外部依賴」：要求用純 HTML／CSS／JavaScript 完成長條圖與統計卡片，避免離線開檔時圖表套件載入失敗。
  • 防呆與重置功能：加入「重置／清除」按鈕，方便老師在下一班或下一輪調查時一鍵歸零。

（一） 情境 A 示範提示詞（班級即時投票與長條圖）

請用繁體中文產生一個單一 HTML 檔案（HTML、CSS、JavaScript 寫在同一個檔案中，不需要外部圖表套件或網路資源）。 主題是「班級即時投票與長條圖統計器」，適合國小課堂投影使用。 功能需求： 1. 顯示一個可自訂的投票題目與至少 4 個選項按鈕（預設題目可為「本學期班級最想去的校外教學地點」）。 2. 每次點擊某個選項的「投一票」按鈕，該選項票數加 1，並即時更新總票數、各選項百分比與純 CSS 橫向長條圖長度。 3. 提供「自訂題目與選項」輸入區與「全部歸零重置」按鈕，方便老師在不同課堂重複使用。

（二） 情境 B 示範提示詞（每週閱讀與生活習慣分類統計）

請用繁體中文產生一個單一 HTML 檔案（所有程式碼寫在同一個檔案中，不依賴外部套件）。 主題是「每週閱讀與生活習慣分類統計器」，適合國小學生記錄與分析一週數據。 功能需求： 1. 可切換統計主題（例如：「每週閱讀分鐘數」或「每日喝水／運動次數」），並提供星期一到星期日的數值輸入或加減按鈕。 2. 自動計算「本週總計」、「每日平均」與「最高／最低日」。 3. 依據設定的達標門檻，自動將本週表現分類（例如：「穩定達標組」、「持續進步組」、「起步暖身組」）並顯示對應提示與重置按鈕。

四、 80 分鐘（兩節課）教學流程建議

節次／時間 教學環節 老師引導重點與師生活動
第一節
00–15 分		 情境暖身與數據提問 展示情境 A 或情境 B 範例，請學生觀察：如果只有一排數字，要花多久才看得出誰最多、有沒有達標？
第一節
15–30 分		 決定統計項目與分類規則 確定要統計什麼（投票選項或每週習慣數值），以及怎麼算「總數／平均／分類標準」。
第一節
30–40 分		 撰寫提示詞 使用產生器或自行寫出單檔 HTML 提示詞，明定互動按鈕、計算方式與重置功能。
第二節
40–62 分		 AI 產出網頁與測試計算 貼給 AI 產生 .html 檔並開檔操作，實際輸入幾組測試數字，檢查加總、百分比或分類是否算對。
第二節
62–80 分		 抓蟲微調與數據分享 針對算錯、歸零沒清乾淨或版面擁擠的地方請 AI 修正，最後分享自己統計到的有趣結果。

五、 數據抓蟲清單與評量建議

🧮 統計網頁常見「算錯」抓蟲點
  • 百分比加起來怪怪的：總票數為 0 時是否出現 NaN%？可請 AI 在總數為 0 時顯示 0%。
  • 輸入負數或空白：若有人不小心輸入負數或空白字元，網頁是否能安全處理而不出錯？
  • 重置按鈕不完整：按了重置後，總數與圖表是否都回到初始狀態？
✅ 課堂觀察評量重點
  • 資料解讀能力：能否根據統計結果說出清楚的比較或結論？
  • 規則描述能力：提示詞是否清楚交代計算與分類邏輯？
  • 測試驗證習慣：是否會用「極端值或簡單數字（如 1、2、3）」來驗算網頁有沒有算對？
