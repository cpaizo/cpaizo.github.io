前導課程（單元 00）｜開課前 15 分鐘暖身

準備工具與認識 HTML：安裝 Sublime Text 與開啟網頁

在請 AI 幫我們產生互動網頁之前，老師只需要先學會三件超簡單的小事： ① 安裝輕巧的文字編輯器 Sublime Text、② 讓電腦顯示「副檔名」、③ 分清楚「改程式碼」與「看網頁」的兩種開法。

1 下載與安裝 Sublime Text（免費試用、輕巧免設定）

為什麼不用 Windows 內建的「記事本」？因為 Sublime Text 會幫程式碼自動上色、排版整齊，老師就算不會寫程式，也能一眼看出哪裡是文字、哪裡可以改題目！

⬇️ 前往 Sublime Text 官方下載頁 ↗

🪟 Windows 電腦安裝步驟

  1. 進入官網後，點擊 Windows 64 bit 下載安裝檔。
  2. 雙擊下載好的 sublime_text_build_xxxx_x64_setup.exe。
  3. 一路按 Next（下一步）→ Install（安裝）→ Finish（完成） 即可。
  4. （選用小技巧）安裝過程中看到 Add to explorer context menu 可打勾，之後對檔案按右鍵就能直接選「Open with Sublime Text」。

🍎 Mac 電腦安裝步驟

  1. 進入官網後，點擊 macOS 下載 .dmg 映像檔。
  2. 雙擊打開下載的檔案。
  3. 將 Sublime Text 圖示拖曳進右側的 Applications（應用程式） 資料夾即完成安裝。

2 必學關鍵：認識「副檔名」與打開顯示設定

電腦是靠檔名最後面的「點（.）＋英文」來決定要用什麼軟體打開檔案。我們做的互動網頁，副檔名一定是 .html。

✅ 黃鶴樓.html

正確的網頁檔！圖示通常會變成 Chrome 或 Edge 瀏覽器的樣子，點兩下就能變成互動網頁。

❌ 黃鶴樓.html.txt

最常見新手地雷！因為電腦預設把 .txt 藏起來，老師以為存成網頁了，結果點開還是純文字。

👀 怎麼讓 Windows 電腦顯示副檔名？（只需設定一次）

  1. 打開任意一個資料夾（檔案總管）。
  2. Windows 11：點上方工具列的 「檢視」→「顯示」→ 勾選「副檔名」。
  3. Windows 10：點上方選單的 「檢視」→ 右側勾選「副檔名」。

3 同一個 .html 檔案，有「兩種打開方式」

這是最重要也最容易搞混的地方：同一個檔案，用不同軟體打開，看到的樣子完全不同！

✏️ 模式 A：編輯程式碼（改內容、貼上 AI 程式碼）

  • 怎麼開：對 .html 檔案按滑鼠右鍵 → 開啟檔案 → 選擇 Sublime Text（或先開 Sublime Text 再把檔案拖進去）。
  • 看到什麼：滿滿的英文標籤與文字（例如 <h1>、<button>）。
  • 何時用：要貼上 AI 產生的程式碼，或老師想自己修改題目文字時。
  • 重要動作：改完一定要按 Ctrl + S（Mac 為 Cmd + S）存檔！

🌐 模式 B：觀看網頁（上課投影、給學生操作）

  • 怎麼開：直接對 .html 檔案快速點兩下左鍵（預設會用 Chrome / Edge 瀏覽器打開）。
  • 看到什麼：漂亮的按鈕、顏色與互動畫面，完全看不到程式碼。
  • 何時用：上課投影在教室大屏，或傳到平板讓學生體驗互動時。
  • 重要動作：如果在 Sublime Text 改了字並存檔，回到瀏覽器按 F5（重新整理） 就會看到最新畫面！

🎮 現場體驗：點按鈕切換同一個檔案的兩種面貌

Sublime Text — hello.html 編輯模式：可修改文字並按 Ctrl+S 存檔
<!DOCTYPE html> <html lang="zh-Hant"> <body> <h1>歡迎來到五年甲班的互動課堂！</h1> <button onclick="alert('你成功打開第一個 HTML 網頁了！')">點我測試</button> </body> </html>

歡迎來到五年甲班的互動課堂！

4 老師 3 分鐘熱身任務：做出你的第一個 test.html

  1. 打開剛安裝好的 Sublime Text，新增一個空白分頁（Ctrl + N）。
  2. 點擊下方「複製程式碼」，貼進 Sublime Text 裡。
  3. 按 Ctrl + S 存檔，檔名輸入 test.html（存放在桌面最方便找）。
  4. 回到桌面找到 test.html，點兩下用瀏覽器打開，看看是不是變成互動按鈕了！
<!DOCTYPE html> <html lang="zh-Hant"> <head> <meta charset="UTF-8" /> <title>我的第一個互動網頁</title> </head> <body style="font-family: sans-serif; text-align: center; padding: 50px; background: #faf7f2;"> <h1 style="color: #0f766e;">🎉 老師成功建立第一個 HTML 網頁！</h1> <p>試著在 Sublime Text 修改這行字，存檔後回瀏覽器按 F5 重新整理看看！</p> <button onclick="alert('準備好進入《黃鶴樓》課程囉！')" style="padding: 12px 24px; font-size: 18px; border-radius: 10px; background: #0f766e; color: white; border: none; cursor: pointer;"> 點我歡呼一下 </button> </body> </html>
