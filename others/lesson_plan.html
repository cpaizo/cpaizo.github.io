108課綱 國中資訊科技 教學活動設計簡案

單元名稱：微型電腦與 IPO 模型
授課年級：國中七年級
授課時間：10 分鐘（試教簡案）
教材來源：Micro:bit 官網與自編教材

一、 學習重點與學習目標

(一) 學習重點對應

學習表現（Performance Standards） 學習內容（Learning Content）
  • c-IV-1 能理解資訊科技系統之基本運作原理。
  • a-IV-1 能主動探索資訊科技新知，並具備運用資訊科技解決問題的興趣。
  • 資 系統 H-IV-1 資訊科技系統之基本組成元素（Input-Process-Output）。
  • 資 系統 H-IV-2 常見微型處理器與硬體元件功能。

(二) 學習表現與內容雙向細目對照表

學習維度 學習表現 (動詞) 學習內容 (主題) 學習目標 (具體行為敘述)
認知 c-IV-1 (理解) H-IV-2 (元件功能) 能指認 micro:bit 正背面的核心元件（按鈕、LED、CPU、感測器）並說出其功能。
技能 c-IV-1 (分析) H-IV-1 (IPO模型) 能運用 IPO 模型，拆解微型電腦處理資料的運作流程（如：智慧計步器）。
情意 a-IV-1 (探索) H-IV-2 (生活應用) 能體會軟硬體結合的原理，並主動舉出 1~2 個生活中的 IPO 應用實例。

二、 議題融入與跨領域連結

議題融入 安全教育 安 J4 理解生活周遭的安全防護機制與原理。
說明：講述加速度計（Input）時，連結「獨居長者跌倒警示系統」或「自行車撞擊報警器」，引導學生思考科技對人類安全的防護價值。
跨領域連結
  • 自然科學領域（理化）：連結「運動與力」概念，說明加速度計如何將物理動態轉換為數位訊號。
  • 健康與體育領域（健體）：連結「智慧運動管理」，以智慧計步器拆解 IPO 運作，展現科技在運動健康的應用。

三、 教學設備與資源

micro:bit V2 開發板、電腦、單槍投影機、MakeCode 模擬器、黑板與彩色粉筆。

四、 教學活動設計流程

教學活動內容及實施方式 時間 備註（評量方式與輔助）
一、 引起動機：生活情境連結
  • 展示 micro:bit 實體教具，拋出生活情境：「智慧手環如何知道你在走路？自動門如何知道有人靠近？」
  • 引導思考：微型電腦如何感知外界並做出反應？
 1.5 分 【評量方式】
  • 口頭/觀察評量：評估能否指認正背面元件並說明功能（對應認知目標）。
  • 情境問答評量：以「智慧計步器」檢核能否正確連結元件與 IPO 角色（對應技能目標）。
【學習輔助與教具】
  • 實體教具：micro:bit V2 開發板。
  • 視覺輔助：黑板板書呈現 IPO 結構圖與顏色標註（藍-Input / 綠-Process / 紅-Output）。
【議題融入與跨領域】
  • 安全教育（安 J4）：跌倒偵測。
  • 自然/健體：運動數據採集。
二、 發展活動：IPO 模型與硬體大解密
  • 建構 IPO 架構：講述 Input（輸入）➔ Process（處理）➔ Output（輸出）資料流向。
  • 實物觀察與拆解：
    • 正面：觀察按鈕 (Input) 與 5x5 LED 網格 (Output)。
    • 背面：指認 CPU 處理器 (Process)、加速度計感測器 (Input)。
  • 思考實踐：以「搖晃 micro:bit 觸發心形圖案」分析數據傳輸路徑。
 6.0 分
三、 綜合與評量活動：情境應用與總結
  • 隨堂提問評量：以「智慧計步器」情境請學生拆解 IPO（加速度計 ➔ CPU ➔ LED）。
  • 生活遷移與總結：引導學生舉例生活中的 IPO 應用（如長者防跌警報器），預告下節課進行 MakeCode 程式實作。
 2.5 分

附錄二：微型電腦（micro:bit V2）硬體對照表

元件名稱 板面位置 IPO 角色分類 功能說明
A / B 按鈕 正面 Input 透過實體按壓輸入開關訊號。
加速度計 背面 Input 偵測板身的搖晃、傾斜、自由落體與動態加速度變化。

5x5 LED 網格 正面 Output 呈現圖案、文字、數字或閃爍動畫。
